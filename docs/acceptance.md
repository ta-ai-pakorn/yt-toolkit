# Checklist ตรวจมือ

## M1 (ทำบน Windows 10/11)
| AC | ขั้นตอน | ผ่าน |
|---|---|---|
| AC-LIFE-01 | สร้างบัญชีผู้ใช้ Windows ใหม่ ลงแค่ Git ทำตาม README ข้อ 1-4 จับเวลาจาก clone ถึงเบราว์เซอร์เปิดหน้าแรก ต้อง ≤ 10 นาที | ☐ |
| AC-LIFE-02 | ปิดแล้วดับเบิลคลิก `start.bat` อีกครั้ง หน้าแรกต้องขึ้นภายใน 5 วินาที | ☐ |
| AC-LIFE-02b | ทดสอบหน้าจอเมื่อเปิดไม่สำเร็จ: ปิดโปรแกรมก่อน แล้วสร้าง*โฟลเดอร์*ชื่อ `app.lock` ไว้ในโฟลเดอร์ `run\` จากนั้นดับเบิลคลิก `start.bat` ภายในราว 30 วินาที หน้าต่างต้องค้างอยู่และแสดงข้อความ "เปิดโปรแกรมไม่สำเร็จ" พร้อมที่อยู่ไฟล์ log และใน `run\logs\app.log` ต้องมีบรรทัดที่พูดถึงไฟล์ lock (`app.lock`) เสร็จแล้วลบโฟลเดอร์ `run\app.lock` ทิ้ง | ☐ |
| AC-LIFE-03 | ขณะเปิดอยู่ ดับเบิลคลิก `start.bat` ซ้ำ มีไอคอน YT Toolkit ที่มุมขวาล่างแค่ไอคอนเดียว และเบราว์เซอร์เปิดแท็บไปที่ตัวเดิม | ☐ |
| AC-LIFE-04 | ปิดได้ทั้ง 3 ทาง: `stop.bat` / เมนู tray / ปุ่มในหน้าตั้งค่า ทุกทางแล้วไอคอนหายและ `run/app.json` ถูกลบ | ☐ |
| AC-LIFE-05 | ถอดเน็ตแล้วเปิด `start.bat` ขั้น 1/4 ต้องข้ามภายใน 15 วินาที แล้วแอพเปิดได้ | ☐ |
| AC-SEC-01 | จากเครื่องอื่นในวงเดียวกัน เปิด `http://<IP เครื่องนี้>:8787` ต้องเชื่อมต่อไม่ได้ | ☐ |
| ffmpeg | เครื่องใหม่ (ไม่มี ffmpeg) หลังเปิดแอพ 2-3 นาที หน้าตรวจสุขภาพต้องแสดง ffmpeg "พร้อม" | ☐ |

## M2 (ทำบน Windows 10/11)

|---|---|---|

| AC-FRAME-06 | โหลดภาพเฟรมเดียว (ปุ่ม "โหลดภาพนี้" ในเมนูคลิกขวา) และโหลด zip ("โหลดทั้งหมด (.zip)") ภาพเดียวเริ่มโหลดทันทีผ่านเบราว์เซอร์ ชื่อไฟล์เป็น `frame_HH-MM-SS.jpg` · zip ส่งเข้าคิว (ตั้งแต่ M4, BRD #86) ไฟล์อยู่ในโฟลเดอร์ของคลิป แล้วเปิด zip ดู ต้องมีไฟล์ภาพครบตามจำนวนเฟรมที่เห็นในหน้า เปิดภาพได้ทุกไฟล์ | ☐ |
| AC-FRAME-07 | คลิกขวาที่เฟรมเวลา 00:01:30 → "คัดลอกลิงก์ช่วงนี้" แล้ววางในแถบที่อยู่ของแท็บใหม่ ต้องเปิดคลิปเดิมที่วินาทีที่ 90 และมี toast "คัดลอกแล้ว" · ลองเปิดเมนูด้วยคีย์บอร์ด (Tab ไปที่เฟรมแล้วกด Shift+F10 หรือปุ่ม Menu) เลือกได้เหมือนกัน | ☐ |
| AC-FRAME-09 | คลิกขวาที่ภาพเฟรม → "คัดลอกภาพ" แล้ววางใน LINE (หน้าต่างแชต), Word และ PowerPoint ทีละโปรแกรม ต้องได้ภาพเฟรมนั้นทุกโปรแกรม และมี toast "คัดลอกภาพแล้ว" | ☐ |
| AC-IN-10 | เปิดเพลงในยูทูปแล้วกดเล่น "มิกซ์" คัดลอกลิงก์จากแถบที่อยู่ (มี `list=RD...`) มาวางในแอพ ต้องขึ้นกล่องถาม "ลิงก์นี้เป็นมิกซ์อัตโนมัติของยูทูป..." เลือก "ทั้งมิกซ์ (25 คลิปแรก)" ต้องเห็นแถวมิกซ์ ชื่อมิกซ์ จำนวนไม่เกิน 25 คลิป และหมายเหตุ "มิกซ์อัตโนมัติ แต่ละคนอาจได้รายการไม่เหมือนกัน" | ☐ |
| AC-IN-12 | ในโปรแกรม LINE (คอมพิวเตอร์) ส่งข้อความหาตัวเองแบบที่คนส่งงานมา: บรรทัดทักทาย, "1. <ลิงก์คลิป>", "2. <ลิงก์คลิป> ขอบคุณครับ" แล้วคัดลอกทั้งข้อความมาวางในแอพ ต้องได้แถวคลิปครบตามจำนวนลิงก์ ไม่มีแถวสีแดง และมีบรรทัดจาง "ข้ามข้อความที่ไม่ใช่ลิงก์" ใต้รายการ | ☐ |
| AC-IN-15 | เปิด YouTube Music เลือกเพลย์ลิสต์ที่ YouTube Music จัดไว้ (ลิงก์มี `list=RDCLAK...`) คัดลอกลิงก์มาวาง ต้องได้แถวเพลย์ลิสต์ปกติ (ไม่มีหมายเหตุมิกซ์ จำนวนคลิปตรงกับในแอป YouTube Music) และกด "ดูคลิปในเพลย์ลิสต์" เห็นรายชื่อคลิป | ☐ |

| M2-RECENT | หลังวางหลายลิงก์ตามข้อบน กดเปิดคลิปหนึ่งคลิป แล้วกลับหน้าแรก คลิปที่เปิดต้องขึ้นในส่วน "ล่าสุด" ส่วนคลิปที่แค่วางไว้แต่ไม่ได้เปิดต้องไม่ขึ้น | ☐ |
