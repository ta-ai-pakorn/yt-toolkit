> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Tasks inside one wave run as parallel subagents, each in its own controller-created git worktree.

**Goal:** On a W2 clip error, a failed queue job or a failed sharp capture with `E_AGE_RESTRICTED` / `E_VIDEO_PRIVATE`, staff press "ใช้บัญชียูทูปชั่วคราว", import a `cookies.txt` exported from a Chrome incognito window, and the app retries the same thing signed in; the sign-in lives in memory only and is deleted by itself (2 h, app shutdown, or queue idle 10 min after a job that used it).

**Spec:** `docs/superpowers/specs/2026-10-06-m5c-temporary-youtube-account-design.md` (binding). Research: `docs/m5c-prep.md`.

### Open questions / rulings for the controller
1. Signed-in probes are kept in memory process-wide until the account is cleared/replaced (spec says "for the job only" and "a reload re-probes"); keeps W2 panels working with fewer signed-in requests; never on disk.
2. W2 panels' own fetches (subtitle files, storyboard images, pinned comment) stay anonymous; only GET /videos/{id}, queue jobs and capture retry (spec §2.4 list).
3. "ลบอัตโนมัติภายใน HH:MM" is a remaining-time countdown ("02:00") per spec §6; it can read like a clock time — confirm with Pete.
4. File picker has no Thai label in spec §7; plan uses accessible name "cookies.txt".
5. Diagnostics report is not in the app yet; canary test covers logs, app.log, SSE, API bodies, /health, GET /cookies and files.
6. Members-only fixtures are reconstructed from YouTube's reason text through yt-dlp's raise_no_formats path, not captured live.
7. Failed-job toast: "ใช้บัญชียูทูปชั่วคราว" becomes the main action, "ดูรายละเอียด" the secondary (sonner cancel) button; removed-account toast uses existing "ปิด" as its dismiss action.
8. Clips opened only with the account do not appear in history/"ล่าสุด" (no DB row).
