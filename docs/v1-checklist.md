# Checklist ตรวจมือก่อนปล่อย v1.0.0 (รอบ D2)

ไฟล์นี้ใช้เฉพาะพิธครับ มีแต่สิ่งที่ระบบอัตโนมัติตรวจแทนไม่ได้ คือต้องใช้เครื่อง Windows จริง ยูทูปจริง บัญชีจริง นาฬิกาจับเวลา โปรแกรมอ่านหน้าจอ หรือตาของคนจริง ใช้เวลาประมาณ 3-3.5 ชั่วโมง (รวมข้อ 39-43 ที่ต้องปิดเครื่องจริง) นั่งทำรอบเดียวจบได้ครับ ส่วนใหญ่เป็นเวลารอโหลดกับรอเวลานับถอยหลัง

**เตรียมของก่อนเริ่ม**

- บัญชี Windows ใหม่ (ไม่ใช่บัญชีที่เคยลงโปรแกรมนี้) ที่ลงแค่ Git
- บัญชี Google สำรองของพิธ สำหรับข้อ 27-28 ต้องมีคลิปจำกัดอายุหรือคลิปส่วนตัวที่บัญชีนี้ดูได้
- เครื่องอีกเครื่องที่อยู่ในวง LAN เดียวกัน สำหรับข้อ 30
- นาฬิกาจับเวลา (ในมือถือก็ได้) และ Task Manager (กด Ctrl+Shift+Esc)
- NVDA ที่ติดตั้งแล้ว สำหรับข้อ 35-36
- โปรแกรมไว้เปิดไฟล์ที่ได้ เช่น PowerPoint, VLC, Notepad, Obsidian และ LINE สำหรับวางข้อความ

**วิธีใช้ตาราง**

- ท้ายคอลัมน์ "ทำอะไร" มีรหัส AC ที่ชี้ไปยังแถวใน [docs/acceptance.md](acceptance.md) ซึ่งเขียนขั้นตอนละเอียดและลิงก์คลิปทดสอบไว้ อ่านแถวนั้นประกอบเมื่อสงสัย
- คอลัมน์ "ผล" ปล่อยว่างไว้ ตรวจแล้วเติม ผ่าน, ไม่ผ่าน หรือตัวเลขที่วัดได้
- ข้อที่ไม่ผ่านให้จดอาการไว้ แล้วกด "คัดลอกข้อมูลแจ้งปัญหา" วางเก็บไว้ อย่าเพิ่งติดแท็ก `v1.0.0` จนกว่าจะผ่านครบ
