# Checklist ตรวจมือก่อนปล่อย v1.0.0 (รอบ D2)

ไฟล์นี้ใช้เฉพาะพิธครับ เป็นรายการสิ่งที่ระบบอัตโนมัติตรวจแทนไม่ได้ ต้องใช้เครื่อง Windows จริง ยูทูปจริง และตาของคนจริง เวลาทั้งหมดราว 4-5 ชั่วโมงในรอบเดียว ถ้าแบ่งเป็นสองช่วงให้หยุดที่ข้อ 17 ครับ

**เตรียมของก่อนเริ่ม**

- บัญชี Windows ใหม่ (ไม่ใช่บัญชีที่เคยลงโปรแกรมนี้) ที่ลงแค่ Git
- บัญชี Google สำรองของพิธ สำหรับข้อ 27-29 ต้องมีคลิปจำกัดอายุหรือคลิปส่วนตัวที่บัญชีนี้ดูได้
- เครื่องอีกเครื่องที่อยู่ในวง LAN เดียวกัน สำหรับข้อ 31
- นาฬิกาจับเวลา (ในมือถือก็ได้) และ Task Manager (กด Ctrl+Shift+Esc)
- NVDA ที่ติดตั้งแล้ว สำหรับข้อ 36-37
- โปรแกรมไว้เปิดไฟล์ที่ได้ เช่น PowerPoint, VLC, Notepad, Obsidian และ LINE สำหรับวางข้อความ
- ลิงก์คลิปทดสอบ มีอยู่ในแถวของแต่ละข้อใน [docs/acceptance.md](acceptance.md) ครับ

**วิธีใช้ตาราง**

- คอลัมน์ "ทำอะไร" ท้ายสุดมีรหัส AC ที่ชี้ไปยังแถวใน [docs/acceptance.md](acceptance.md) ซึ่งเขียนขั้นตอนละเอียดไว้ อ่านแถวนั้นประกอบเมื่อสงสัย
- คอลัมน์ "ผล" ปล่อยว่างไว้ ตรวจแล้วเติม ผ่าน, ไม่ผ่าน หรือตัวเลขที่วัดได้
- ข้อที่ไม่ผ่านให้จดอาการไว้ แล้วกด "คัดลอกข้อมูลแจ้งปัญหา" วางเก็บไว้ อย่าเพิ่งติดแท็ก `v1.0.0` จนกว่าจะผ่านครบ

## ข้อมูลอ้างอิง

- ความละเอียดของแต่ละข้อ (ลิงก์คลิปทดสอบ ขั้นตอนย่อย) อยู่ใน [docs/acceptance.md](acceptance.md) ตามรหัส AC ที่ระบุท้ายข้อ
- แถวที่มีป้าย `auto:` ใน acceptance.md มีเทสต์อัตโนมัติพิสูจน์ส่วนที่ระบบตรวจเองได้แล้ว ข้อในตารางนี้ครอบคลุมเฉพาะส่วนที่ต้องใช้คนจริงและยูทูปจริง
- ตรวจครบทุกข้อและผ่านแล้ว จึงค่อยติดแท็ก `v1.0.0` และเติมวันที่ปล่อยในหัวข้อ 1.0.0 ของ [CHANGELOG.md](../CHANGELOG.md)
