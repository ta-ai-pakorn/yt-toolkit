# ไอเดียที่จดไว้ (ยังไม่อยู่ในรอบไหน)

ไอเดียจากพิธที่ตกลงว่าจะทำ แต่ยังไม่ได้ผูกกับรอบงาน · ก่อนเริ่มรอบใหม่ให้เปิดไฟล์นี้ดูว่าจะหยิบข้อไหนเข้ารอบ

## หน้า "คีย์ลัด" (พิธ 2026-10-05)
- **ปัญหา:** แอพมีคีย์ลัดหลายตัวแล้ว แต่ผู้ใช้ไม่รู้ว่ามีอะไรบ้าง
- **ทำ:** หน้าต่างหรือเมนู "ดูคีย์ลัด" ที่รวมคีย์ลัดทั้งแอพไว้ที่เดียว (พิธประเมินว่างานไม่ใหญ่)
- **คีย์ลัดที่มีอยู่ตอนนี้:**
  - Shift+F10 / ปุ่ม ContextMenu เปิดเมนูของภาพเฟรม
  - ลูกศรซ้าย/ขวาเปลี่ยนภาพใน lightbox
  - Esc ปิดช่องค้นหาในทรานสคริปต์
  - Enter เปิดคลิปจากรายการผล
- **จะมีเพิ่มในรอบ B2:** T สลับโหมดโรงภาพยนตร์
- **ก่อนทำ:** ไล่หาคีย์ลัดทั้งหมดในโค้ดอีกรอบ เพราะรายการข้างบนมาจากการค้นคร่าว ๆ
- **คำถามที่ต้องตัดสินตอนออกแบบ:**
  - เปิดหน้าต่างด้วยปุ่ม "?" ไหม (แบบ YouTube/Gmail)
  - วางทางเข้าไว้ที่หัวหน้าจอหรือที่หน้าตั้งค่า

## รองรับเว็บอื่นนอกจากยูทูป เช่น TikTok (พิธ 2026-10-05)
- **ที่มา:** yt-dlp รองรับเว็บวิดีโอเกือบ 1,900 เว็บ (TikTok, Facebook, Instagram, Vimeo ฯลฯ) แต่แอพตอนนี้ออกแบบมาสำหรับยูทูปอย่างเดียว
- **ใช้ต่อได้เกือบทั้งหมด:** คิวโหลด, โหลด mp4/mp3, ซับที่ฝังมากับคลิป, ประวัติ, ตั้งค่า
- **ผูกกับยูทูปอยู่ ต้องรื้อหรือซ่อน:**
  - รหัสคลิปและลิงก์ที่รับได้ (ตอนนี้รับเฉพาะรหัสยูทูป 11 ตัว และใช้รหัสนี้เป็นชื่อแคช)
  - ตัวเล่นในหน้าคลิป (ฝังตัวเล่นยูทูป), ภาพเฟรมเร็ว (storyboard ของยูทูป), ถ่ายภาพคมตรงจุด (วิธี sidx ที่ทดลองกับยูทูป)
  - SponsorBlock, บท (chapters), ปุ่ม "เปิดในยูทูป", การพักคิวเมื่อยูทูปขอตรวจสอบ
- **ข้อควรคิดก่อนทำ:** TikTok/Instagram มักต้องล็อกอิน (คุกกี้) ซึ่งเกี่ยวกับรอบ C; ลายน้ำของ TikTok; เงื่อนไขการใช้งานของแต่ละเว็บ
- **ข้อเสนอ:** ทำเป็นรอบแยกหลังรอบ C เริ่มจาก TikTok เว็บเดียว หน้าคลิปแบบ "โหลดอย่างเดียว" (ไม่มีตัวเล่นฝัง/ภาพเฟรม) แล้วค่อยเพิ่มความสามารถทีละเว็บ

## คัดลอกข้อความในภาพ (OCR) (ครีมเสนอ 2026-10-05)
- **ทำ:** ปุ่ม "คัดลอกข้อความในภาพ" ใน lightbox ของภาพที่ถ่ายไว้ (รอบ B2) เหมาะกับคลิปสอนเขียน prompt หรือโค้ด
- **ขอบเขต:** สเปกรอบ B2 ระบุว่าอยู่นอกขอบเขตรอบนี้
