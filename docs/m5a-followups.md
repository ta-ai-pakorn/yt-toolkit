# เรื่องค้างจาก M5 รอบ A (ช่วงเวลา · แยก chapter · SponsorBlock)

รีวิวทั้ง branch และรอบแก้สุดท้าย (2026-10-02) ตัดสินว่าเรื่องเหล่านี้ไม่ขวางการใช้งานปกติ เก็บไว้ทำในรอบถัดไปหรือ M6

## ต้องให้พิธตัดสินก่อน
- **โฆษณาคลุมทั้งช่วงที่ตั้ง หรืออยู่นอกช่วงทั้งหมด:** งานไม่ตัดอะไรและได้หมายเหตุ "ไม่มีข้อมูลจากชุมชน ไม่ได้ตัดโฆษณา" ทั้งที่ชุมชนมีข้อมูล ผลลัพธ์ถูกต้อง แต่ข้อความควรแยกกรณี (`core/handlers.py` ราว 323-325)
- **ชื่องานในคิวบอก "· ตัดโฆษณา"** แม้หมายเหตุบอก "ไม่ได้ตัดโฆษณา" (`web/src/components/queue/job-text.ts:21`)
- **แท็บเสียงกด "แยกไฟล์ตาม chapter" ไม่ได้** เมื่อแท็บวิดีโอเลือกฝังซับไว้ ทั้งที่งานเสียงไม่ฝังซับ (`audio-panel.tsx:46` ตาม brief เดิม)
- **คลิป HDR:** ตัดช่วงหรือตัดโฆษณาแบบตรงเป๊ะแปลงเป็นสีมาตรฐาน (8-bit SDR) คลิป HDR จึงอาจดูซีดลง
- **network test:** ต้องเลือกคลิปจริงให้ `[advanced] chapters_clip` (มี chapter ≥ 3) และ `sponsor_clip` (มีข้อมูล SponsorBlock) ใน `tests/network_videos.toml` · ขนาดโหลดโดยประมาณ 50-120 MB (ยังไม่ได้วัดจริง) · รันเมื่อพิธอนุมัติเท่านั้น

## แก้ได้เลยเมื่อมีโอกาส
- ปุ่ม "ใช้เวลาที่ตัวเล่นอยู่ตอนนี้" ข้างช่องเวลา (`range-fields.tsx:41`) ยังอ่าน `currentMs` ระหว่างตัวเล่นกำลังโหลดหลังกระโดดเวลา ควรใช้ `markTimeMs()` แบบปุ่มใต้ตัวเล่น
- ปุ่มตั้งจุดและเมนูภาพเฟรมไม่เช็กว่าคลิปตั้งช่วงได้ไหม (คลิปสด) กดแล้วได้ค่าที่ล้างไม่ได้และป้าย "ใช้ตัวเลือกขั้นสูงอยู่" ค้าง
- บันทึกหมวด SponsorBlock ล้มติดกันสองครั้ง ค่าบนจอคืนเป็นสถานะหลังติ๊กครั้งแรก (ที่ server ไม่ได้รับ) จนกว่าจะโหลดค่าตั้งใหม่
- PRD ราวบรรทัด 706: ข้อความเรื่องพื้นที่ดิสก์ 3 เท่า ควรบอกว่าตัดโฆษณาใช้ 3 เท่าเฉพาะเมื่อมีช่วงโฆษณาจริง
- งาน `splitChapters` ที่มีช่วงเวลาหรือ SponsorBlock ปนมา (API ห้ามอยู่แล้ว) ยังเรียก SponsorBlock ก่อนทิ้งผล
- แยก chapter ย้ายไฟล์ทีละไฟล์ ถ้าดิสก์เต็มกลางทาง ไฟล์ chapter แรก ๆ จะค้าง และลองใหม่ได้ ` (2)`
- โค้ดเลือกรูปแบบเสียงซ้ำกันระหว่างทางแยก chapter กับทางปกติ (`handlers.py`) ควรรวมเป็นฟังก์ชันเดียว
- ชื่อไฟล์กรณี `file_cap <= 0` (`<videoId><tail>`) ตัวกวาดไฟล์ค้างไม่รู้จัก (เกิดยากมาก)
- `is_stage` ใช้ `\d` รับเลขที่ไม่ใช่ ASCII ควรเป็น `[0-9]`
- เทสที่ยังขาด: คลิปไม่มีเสียงตอนแยก chapter แบบเร็ว · noAudio + แยก chapter (หลายกรณี) · `NO_CHAPTERS` ของเสียง · metadata ของ chapter เสียง · chapter สุดท้ายเกินความยาวจริง · e2e ของตัวกวาดไฟล์ค้าง · e2e กรณี SponsorBlock/ฝังซับบล็อก chapter, PATCH ล้มแล้วคืนค่า, คลิปสด
- เรื่องเล็กด้านโค้ดและเทสอื่น ๆ ตามรายการใน ledger ของรอบ A (สรุปไว้ในรีวิวสุดท้าย)
- เทส e2e ที่ล้มเฉพาะตอนรันทั้งชุดบนเครื่องที่มีโหลด (ผ่านเมื่อรันเดี่ยว 2026-10-02): `download-tabs.spec.ts:378` (axe แท็บเสียง ธีมสว่าง) และ `player.spec.ts:260` (เล่นช่วงไฮไลต์) · `--repeat-each` ทำให้ `download-tabs.spec.ts:194` ล้มเพราะค่าที่จำไว้จากรอบก่อน
