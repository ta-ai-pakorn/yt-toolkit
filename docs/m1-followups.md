# งานค้างจาก M1 (ยกไป M2 ขึ้นไป)

สรุปจากการรีวิวทีละงานและรีวิวทั้ง branch ของ M1 รายการเหล่านี้ไม่กระทบความปลอดภัยและไม่ทำให้ M1 ใช้งานไม่ได้ จึงเลื่อนไปทำพร้อมงานที่เกี่ยวข้อง

## ควรทำใน M2 (เรื่องที่ผู้ใช้จะเจอ)
- **เปิดแอพไม่ขึ้นแต่ไม่มีอะไรบอก**: `start.bat` เรียก `pythonw` แล้วจบทันที ถ้าแอพพังตอนเริ่มผู้ใช้จะไม่เห็นอะไรเลย ควรให้ `start.bat` รอ `run/app.json` ~20 วินาที ถ้าไม่ขึ้นให้บอกและชี้ไปที่ `run/logs/app.log`
- **อัปเดตขณะแอพเปิดอยู่**: ถ้า `git pull` ได้ `uv.lock` ใหม่ขณะแอพเปิด `uv sync` อาจแก้ไฟล์ใน `.venv` ไม่ได้ แล้วขึ้นหน้าจอ "เปิดโปรแกรมไม่สำเร็จ"
- **yt-dlp เก่าเร็ว**: `start.bat` ใช้ `uv sync --frozen` ผู้ใช้จึงได้ yt-dlp ตาม `uv.lock` เท่านั้น ต้องมีรอบอัปเดต lock เป็นประจำ หรือออกแบบการอัปเดต yt-dlp แยก (หน้าตรวจสุขภาพเตือนเมื่อเก่ากว่า 30 วัน)
- **error ของ API ยังไม่ครบรูปแบบเดียวกัน**: 404/422/500 ที่ FastAPI สร้างเองยังไม่อยู่ในรูป `{"error":{...}}` ควรเพิ่ม exception handler กลางใน `create_app` ก่อนเพิ่ม endpoint ใหม่
- **ช่วงเวลาแคบของ start/stop พร้อมกัน**: (1) ถ้า `stop.bat` รันตอนแอพตัวใหม่กำลังเริ่ม และ `app.json` เก่าชี้ pid ที่ถูกโปรแกรมอื่นใช้ซ้ำ อาจปิดผิดตัว ควรให้ `start()`/`serve()` ลบ `app.json` เก่าทันทีหลังได้ lock และให้ `stop()` อ่าน `app.json` ซ้ำก่อน kill (2) ถ้า `stop()` ถือ lock ชั่วครู่พอดีตอน `start()` ขอ lock `start()` จะรอ 20 วินาทีแล้วเลิก ควรลองขอ lock ซ้ำในลูปรอ
- **หน้าแรก (M2 เขียนใหม่อยู่แล้ว)**: ข้อความแจ้งไม่หายเมื่อแก้ช่อง, `useEffect` ของการวางลิงก์ใช้ deps ว่าง, หัวข้อใช้ `leading-snug`
- `api()` ใส่ `Content-Type: application/json` ทุกครั้งที่มี body จะพังเมื่อส่ง `FormData` (อัปโหลดไฟล์)

## ทำเมื่อถึงงานที่เกี่ยวข้อง
- `LocalOnlyMiddleware` ยังไม่ตรวจ websocket ต้องแก้ก่อนเพิ่ม route แบบ websocket
- เปิด `/index.html.` หรือชื่อย่อ 8.3 ของ Windows ได้ไฟล์ดิบที่ไม่มี token (ไม่อันตราย แค่หน้าเว็บกดปุ่มไม่ได้)
- `ffmpeg.exe`/`ffprobe.exe` อาจถูกแทนที่ไม่พร้อมกันถ้าไฟล์หนึ่งกำลังถูกใช้ (ใช้ได้ทั้งคู่ ไม่เสีย) · ไฟล์ `.part` ค้างใน `bin/` ถ้าแอพถูกฆ่ากลางทาง
- กดติดตั้ง ffmpeg สำเร็จแต่ไม่ได้ดูสถานะที่ตอบกลับ · toast ค้างทับหน้า "ปิดโปรแกรมแล้ว" · ปุ่มปิดโปรแกรมไม่มี spinner
- ย้าย `useHealth` ไปไฟล์ของตัวเองเพื่อเลิกใช้ `eslint-disable`
- ปุ่ม "ตั้งค่า" บนหัวเว็บเป็น `<a role="button">` (โปรแกรมอ่านหน้าจอจะอ่านเป็นปุ่ม)
- จอขาวแวบตอนโหลดสำหรับเครื่องที่ใช้ธีมมืด · `aria-label="Loading"` ของ spinner เป็นภาษาอังกฤษ
- `app.log` ยังไม่หมุนไฟล์ (ใช้ `RotatingFileHandler`)
- ใน `detail` ของ error อาจมี path ที่มีชื่อผู้ใช้ Windows ต้องตัดออกก่อนทำรายงานแจ้งปัญหา (AC-SET-04, M6)
- `subprocess.CREATE_NO_WINDOW` และชื่อ `deno.exe` ยังอยู่นอก `yttoolkit/platform/` ควรย้ายเข้าไป
- เทส: `now_iso`, `open_folder`/`reveal`, `readToken`/`fill`, e2e ที่ fix เวอร์ชัน `0.1.0` และคาดว่าเครื่องมี deno
- CI: ยังไม่ cache browser ของ Playwright · `ubuntu-latest` จะเปลี่ยนเป็น Ubuntu 26 วันที่ 2026-10-19 ให้ดูขั้นตรวจ `web/dist`
